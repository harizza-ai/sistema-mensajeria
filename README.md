# sistema-mensajeria
src.modelo.Sistema de mensajería que permite a usuarios registrados comunicarse mediante conversaciones, gestionando participantes, mensajes e historial. Los mensajes pueden ser de texto, multimedia o encuestas, y cuentan con un estado de lectura que indica si fueron enviados, recibidos o leídos.
